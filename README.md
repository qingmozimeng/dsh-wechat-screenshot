# 清墨截图

> 1.3.1 本地稳定性修复，基于 2026-10-31 的 1.3.0 候选备份；尚未发布。优先阅读 ELECTRON.md。

**跟微信原生截图差不多，由 DeepSeek 与 ChatGPT 联合开发。**

署名：**清墨子梦**。项目由清墨子梦主导，使用 DeepSeek 与 ChatGPT 协作编写、优化和验证；这是个人社区插件。

`dsh-wechat-screenshot` 是 DeepSeek Harness 的 Windows 独立截图插件：在聊天输入框点击剪刀，冻结桌面、框选或选择窗口、添加标注，然后复制或保存图片。独立运行，无需启动微信。

## 两种运行方式

| 方式 | 使用条件 | 说明 |
| --- | --- | --- |
| 基础模式 | Windows 10/11、DSH Web | 支持框选、标注、复制和保存，不隐藏或改动本机窗口。 |
| 独立 GPU 窗口 | Windows、可接入本插件的 Electron 桌面宿主 | 按需启动原生采集进程、独立渲染进程和 GPU 合成；需要宿主按 [ELECTRON.md](ELECTRON.md) 接入。 |

**本文的高流畅度测试结果来自独立 GPU 窗口模式。** 普通浏览器或未接入的桌面宿主不会仅靠安装插件自动获得该模式。插件不会在安装时修改宿主启动文件。

## 功能

- 输入框剪刀入口；独立 Electron 模式支持隐藏 / 保留 DSH 窗口。
- 拖动框选、窗口识别、选区尺寸显示和边缘调整。
- 矩形、椭圆、箭头、画笔、马赛克、文字、序号。
- 撤销 / 重做、复制到系统剪贴板、保存 PNG。
- 原生采集进程在截图结束后退出；截图背景、遮罩和选框由独立窗口合成。
- 当前笔画与已有标注分层绘制；选框边缘使用独立图层。

## 安装

使用本次随附的本地 .tgz 文件安装（安装前停用其他名称的旧截图插件）：

```powershell
dsh plugin --profile web add file:C:/path/to/dsh-wechat-screenshot-1.3.1.tgz
```

其他 profile 请把 `web` 换成实际名称，使用官方桌面客户端时应通过该客户端的插件管理器安装。市场收录需维护者审核；发布 GitHub 仓库不等于已经在市场上架。

如果此前安装了本项目的本地旧版 `dsh-wechat-shot`，请先停用旧版，避免出现两个剪刀入口。本项目和 npm 上其他作者发布的同名旧包无关。

启用后刷新页面。需要独立 GPU 窗口模式时，请继续阅读 [Electron 接入说明](ELECTRON.md)。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点剪刀 / Alt+A | 截图；仅独立 Electron 模式隐藏 DSH 窗口 |
| 剪刀右侧菜单 / Shift+Alt+A | 保留 DSH 窗口截图 |
| 拖动 / 单击高亮窗口 | 框选 / 选中窗口 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Enter / Ctrl+C | 复制截图并退出 |
| Ctrl+S | 保存 PNG 并退出 |
| Esc / 右键 | 取消并恢复窗口 |

Alt+A 是应用内快捷键；如果微信等软件注册了同一个全局快捷键，可能会先截获它。这时使用插件的剪刀按钮即可。

图片默认保存在系统图片目录中的 `Screenshots` 文件夹。复制后可回到输入框按 Ctrl+V 粘贴。

## 性能说明

以下是旧 1.3.0 的历史记录，不能作为 1.3.1 冷启动性能数据。本修复版调整了资源释放策略，未重新测量完整拖动帧率。

在一台 Windows 机器上，以 2560×1440、165Hz 显示器和 AMD Radeon RX 9070 XT 实测独立模式：首次出图约 0.39 秒，后续约 0.18 秒；最后一次桌面拖动测试的动画回调间隔平均 6.06ms、P95 6.20ms。

这些是特定机器的测试结果，不是所有设备的性能保证，也不等于显示器实际呈现帧率。我们用微信截图做过同机对照，目标是接近其跟手体验，并不宣称内部实现或所有场景表现完全相同。

## 本地处理

截图只在用户主动操作时采集，图片在本机处理。原生采集使用临时 BMP 文件，读取后清理；只有用户选择保存时，才写入截图文件夹。没有图片上传服务，也没有安装时自动修改其他应用的脚本。

## 开发

主插件已包含可用的 `client.js` 和独立窗口构建产物，无需用户在安装时编译。

```powershell
npm run check
npm test
cd native-gpu
npm install
npm run build
```

独立窗口的 React 源入口为 `native-gpu/renderer-entry.jsx`，构建脚本会复用主插件界面代码。修改 Electron 主进程或 preload 后需重启桌面宿主。
